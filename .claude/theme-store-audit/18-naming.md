# 18. Naming Themes and Presets

**Source:** https://shopify.dev/docs/storefronts/themes/store/requirements#naming-themes-and-theme-presets

Theme and preset names must be 1-2 words, under 30 characters, and distinct from Shopify products, company names, industries, and existing Theme Store themes.

## Naming Requirements

- [ ] Name is distinct from Shopify products/events/branded content (no "Shopify", "Unite", "Polaris")
- [ ] Name does NOT include company or Partner account name
- [ ] Name is distinct from websites, platforms, or SEO terms (no "Performance", "Mobile", "Sales")
- [ ] Name is distinct from industries/collections (no "Fashion", "Electronics", "Jewelry")
- [ ] One preset takes the name of the parent theme
- [ ] All names are 1-2 words
- [ ] All names are under 30 characters
- [ ] All names are unique from existing Theme Store themes

## Preset/Zip Structure (if multiple presets)

- [ ] Each preset has a unique set of templates in `/listings/<preset-name>/templates/`
- [ ] Preset install state matches its demo store (layout, colors, typography)
- [ ] If only one preset: no `/listings` folder required
