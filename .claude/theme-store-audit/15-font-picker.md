# 15. Font Picker

**Source:** https://shopify.dev/docs/storefronts/themes/store/requirements#font-picker
**Available fonts:** https://shopify.dev/docs/storefronts/themes/architecture/settings/fonts#available-fonts

All fonts must use the `font_picker` setting type. Bold, italic, and bold-italic variants must be loaded via `font_modify`. No custom fonts accepted.

## Checklist

- [ ] All fonts use `font_picker` setting type
- [ ] A default font is loaded (e.g. `default: work_sans_n6`)
- [ ] Fonts used in defaults/presets are currently available Shopify fonts
- [ ] CSS loads bold, italic, and bold-italic variants via `font_modify` filter
- [ ] No custom (non-Shopify) fonts
