# 17. Responsive Images

**Source:** https://shopify.dev/docs/storefronts/themes/store/requirements#responsive-images

Images must use a responsive strategy (srcset / `image_tag` with widths) and lazy load as they enter the viewport. Small icons are exempt from the responsive requirement.

## Checklist

- [ ] All images (except small icons) use a responsive image strategy (srcset / `image_tag` with widths)
- [ ] Images lazy load — loaded only as they enter the viewport, not all at page load
