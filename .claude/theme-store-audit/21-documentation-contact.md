# 21. Documentation and Contact Forms

**Source:** https://shopify.dev/docs/storefronts/themes/store/requirements#documentation-and-contact-forms

Public documentation and a public support contact form are required and must be linked from the Theme Store listing before launch.

## Documentation

- [ ] Theme documentation exists and is publicly accessible
- [ ] Documentation linked from Theme Store listing page
- [ ] Documentation ready before theme launch
- [ ] Copy is grammatically correct and spelling-error free
- [ ] Documentation is consistent with copy in theme settings
- [ ] Documentation kept up to date as Shopify and theme change
- [ ] FAQ section included
- [ ] Support policy specified

## Contact Form

- [ ] Public support contact form exists, linked from Theme Store listing
- [ ] Includes: Name, Email, Store URL (with example), Problem description (text area), File upload, Auto-responder
- [ ] Mobile friendly and directly linkable (not a modal with no URL)
- [ ] No unnecessary fields (budget, phone number, project type)
