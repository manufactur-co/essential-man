# 22. Supporting Your Theme

**Source:** https://shopify.dev/docs/storefronts/themes/store/requirements#supporting-your-theme

2-business-day response SLA on all merchant support requests. Critical bugs must be fixed immediately or the theme risks removal from the store.

## Merchant Support

- [ ] Merchant theme-related questions answered
- [ ] Support requests replied to within 2 business days
- [ ] Technical issues (broken layout, dead links, logical errors) fixed in a timely manner
- [ ] Critical bugs fixed immediately (failure may result in removal from store)

## Installation Quality

- [ ] `.json` files don't include demo store-specific resources (no custom metafields, no `shopify://` URLs)
- [ ] `link_list` Header/Footer settings have `default` of `main-menu` or `footer`
- [ ] Resource-based setting defaults reference resources that exist in all stores
- [ ] `metaobject`/`metaobject_list` settings use only standard definitions
