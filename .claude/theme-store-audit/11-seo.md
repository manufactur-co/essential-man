# 11. Search Engine Optimization (SEO)

**Source:** https://shopify.dev/docs/storefronts/themes/store/requirements#search-engine-optimization
**SEO best practices:** https://shopify.dev/docs/storefronts/themes/seo

Theme must include an SEO metadata snippet, Google rich product snippets (structured data), and must NOT include a `robots.txt.liquid` template.

## Checklist

- [ ] SEO metadata snippet present with: `<title>`, meta description, and canonical URL
- [ ] Google rich product snippets (structured data / JSON-LD) included — validate with Google's Rich Results Test
- [ ] NO `robots.txt.liquid` template in the theme
