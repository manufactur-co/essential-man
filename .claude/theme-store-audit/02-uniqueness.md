# 2. Uniqueness from Other Themes

**Source:** https://shopify.dev/docs/storefronts/themes/store/requirements#uniqueness-from-other-themes

Theme must be fundamentally different from all other Theme Store themes — including your own. Uniqueness must be architectural, not cosmetic. Only Shopify's Skeleton Theme is an approved base; Dawn and Horizon are not eligible.

## Checklist

- [ ] Fundamentally different from all other Theme Store themes (including own)
- [ ] Uniqueness is at the architectural level — not achievable by tweaking settings, colors, or spacing
- [ ] Inventive art direction with clear systems: header/nav, product cards, media treatments, page structure
- [ ] NOT built on Dawn or Horizon — Skeleton Theme is the only approved base codebase
- [ ] A merchant cannot customize it to appear nearly identical to a different Theme Store theme
