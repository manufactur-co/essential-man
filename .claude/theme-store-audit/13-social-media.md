# 13. Social Media

**Source:** https://shopify.dev/docs/storefronts/themes/store/requirements#social-media

Social media icons must be available for merchants. Open Graph and Twitter card tags are required in `<head>`. Social media input placeholders must be left empty.

## Checklist

- [ ] Set of social media icons available for merchants to choose from
- [ ] Open Graph tags present in `<head>`
- [ ] Twitter card tags present in `<head>`
- [ ] Social media placeholder text is left empty (not pre-filled)
