# 20. Demo Stores

**Source:** https://shopify.dev/docs/storefronts/themes/store/requirements#demo-stores

Created via Client transfer store from Partner Dashboard. Authentic content only — no Lorem Ipsum, no apps (with narrow exceptions), proper licensing for all assets.

## Checklist

- [ ] All theme presets have at least one demo store
- [ ] Each demo store matches primary industry and catalog size for its preset tags
- [ ] Demo store install state matches what the demo store shows
- [ ] Bogus Gateway or Shopify Payments test mode enabled; all other checkout options disabled
- [ ] All pages use authentic text (no Lorem Ipsum, no onboarding text, no profanities)
- [ ] `powered_by_link` is not altered — contains only `powered_by_link`
- [ ] No affiliate linking in demo store
- [ ] All Shopify domain links include `rel="nofollow"`
- [ ] No embedded text/buttons in images (exception: text on physical products, infographics, badges, Instagram images)
- [ ] No animated GIFs that could be mistaken for theme functionality
- [ ] No apps used (exception: free product review apps and free translation apps with fully translated content)
- [ ] Appropriate rights obtained for all demo store assets per Partner Agreement
- [ ] Demo store created via Client transfer store from Partner Dashboard (not a dev store with developer preview)
