# 6. Lighthouse Performance and Accessibility

**Source:** https://shopify.dev/docs/storefronts/themes/store/requirements#lighthouse-performance-and-accessibility
**Performance best practices:** https://shopify.dev/docs/storefronts/themes/best-practices/performance

Minimum Lighthouse scores measured across home, product, and collection pages on both mobile and desktop. Sections must contain real content (not empty) when tested.

## Checklist

- [ ] Average Lighthouse **performance score ≥ 60** across home, product, collection pages (mobile + desktop)
- [ ] Average Lighthouse **accessibility score ≥ 90** across home, product, collection pages (mobile + desktop)
- [ ] Sections contain actual images and content during tests (not empty placeholders)

## How to Test

Run Lighthouse manually on a development store, or use Lighthouse CI via GitHub Actions. Shopify also runs tests against a benchmark dataset with real content.
