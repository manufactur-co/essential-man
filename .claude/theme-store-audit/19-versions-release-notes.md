# 19. Theme Versions and Release Notes

**Source:** https://shopify.dev/docs/storefronts/themes/store/requirements#theme-versions-and-release-notes

Every submission — new or update — must include a version number and release notes. This helps merchants identify what version they have and what features are available.

## Checklist

- [ ] Theme has a version number on submission
- [ ] Release notes highlight the main features/changes of the version
