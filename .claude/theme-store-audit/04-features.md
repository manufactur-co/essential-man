# 4. Features

**Source:** https://shopify.dev/docs/storefronts/themes/store/requirements#features

All 21 features below must be supported. Each item notes the required page/context.

## Checklist

- [ ] **Sections Everywhere** — Online Store 2.0 compatible (JSON templates)
- [ ] **Discounts** — item-level + order-level shown on Cart page
- [ ] **Accelerated Checkout Buttons** — on Product page and Cart page; branded colors must NOT be modified
- [ ] **Faceted Search Filtering** — on Collection pages and Search pages (availability, price, type, vendor, variant options)
- [ ] **Gift Cards** — gift card template renders correctly
- [ ] **Image Focal Points** — supported via `image_picker` setting and Files page
- [ ] **Images for Social Sharing** — `page_image` object implemented
- [ ] **Country Selection** — currency/country selector follows UX guidelines
- [ ] **Language Selection** — language selector follows UX guidelines
- [ ] **Multi-level Menus** — nested dropdown menus supported
- [ ] **Newsletter Forms** — email signup section present
- [ ] **Pickup Availability** — displayed on Product page without requiring add-to-cart
- [ ] **Related Product Recommendations** — auto-generated list on product pages
- [ ] **Complementary Product Recommendations** — on product pages
- [ ] **Rich Product Media** — 3D models, Vimeo/YouTube videos on product template, featured product section, and quick view
- [ ] **Search** — search template + predictive search functionality
- [ ] **Selling Plans** — shown on Cart page and Customer page
- [ ] **Shop Pay Installments** — banner on product page
- [ ] **Unit Pricing** — on Collection, Product, Cart, and Customer pages
- [ ] **Variant Images** — shown when associated variant is selected
- [ ] **Follow on Shop** — `login_button` filter implemented; branded colors must NOT be modified
