# 16. Color System

**Source:** https://shopify.dev/docs/storefronts/themes/store/requirements#color-system
**Color system best practices:** https://shopify.dev/docs/storefronts/themes/best-practices/design/color-system

Minimum 4 colors required. Every background color setting must have a corresponding foreground color setting. All color settings must use `type: color`.

## Checklist

- [ ] Minimum 4 colors defined in settings
- [ ] Every background color setting has a corresponding foreground color setting
- [ ] All color settings use `type: color`
